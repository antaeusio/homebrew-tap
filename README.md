# Antaeus Homebrew tap

Homebrew formulae for [Antaeus](https://antaeus.io), the open-source semantic
policy engine and CLI.

```sh
brew install antaeusio/tap/antaeus
antaeus version
```

Formulae install the prebuilt archives attached to each
[Antaeus release](https://github.com/antaeusio/antaeus/releases) and pin their
SHA-256 checksums. They are generated from each release's `SHA256SUMS` by
[`scripts/homebrew-formula`](https://github.com/antaeusio/antaeus/blob/main/scripts/homebrew-formula).

Report problems in the [main repository](https://github.com/antaeusio/antaeus/issues).
